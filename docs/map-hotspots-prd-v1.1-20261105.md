## 1. 产品定位

以中国地图场景为主界面，把全国分散的资源、监控设备、作业点和组合场景作为热点呈现。用户从地图发现资源，点击热点直接打开画面，再按需控制、对讲、标绘、推送或组织会商。

产品的主次关系为：**地图 → 个体热点 → 视频画面 → 画面控制 → 设备信息与辅助业务**。

地图是唯一底板；列表、工具和业务面板均围绕地图展开。页面不采用由大型顶栏、常驻统计卡和左右固定详情栏占满的后台管理布局。

三条业务主线：

- **显**：定位热点、打开画面、多路组合、自由布局与宫格上屏。
- **控**：画面内容控制、云台、光学、预置位、对讲、控制权。
- **联**：画面／态势推送、协同会商、独立消息。

## 2. 范围与交付边界

### 2.1 本版包含

地图浏览、个体热点及图例、资源与场景列表、省份简称快捷切换、文本与语音搜索、视频开窗及布局、画面内容控制、云台与对讲、地图标绘、推送与回执、会议与会中消息、普通消息与附件、场景保存、抓拍／录像／态势快照、4K 显示适配。

### 2.2 本版不作为交付前提的能力

真实地图服务接入、设备接入协议、实时音视频链路、服务器控制权仲裁、真实推送投递、会议服务端、远端消息投递、正式账号鉴权、三维地图、大屏投放系统和自动事件联动。

| 能力 | 当前原型 |

## 4. 视觉与动态设计

### 4.1 视觉基线

以第一版已交付样式为依据，恢复深蓝半透明面板、冷蓝色强调、细描边、柔和阴影、字体与信息层次。保留后续已修正的交互关系，不恢复早期占据大量地图面积的布局。

- 地图的影像、地形和道路保持可辨认，避免整体过暗或过度染色。
- 资源列表、窗口、工具、图例和业务面板采用一致的深蓝透明材质。
- 强调色用于选中、可操作入口和关键状态，不用大片高饱和色挤压底图。
- 中文名称优先；英文辅助标识不承担核心操作含义。
- 图标、正文、辅助信息、时间码、编号各有稳定层级。
- 离线、禁用、选中、控制中、通话中、共享中和录制中均有明确状态。

### 4.2 动态规则

动态应服务于操作和状态理解：

| 场景 | 动态要求 |
| --- | --- |
| 地图定位 | 平滑过渡到目标视野，避免突然跳变 |
| 热点选中 | 短暂定位环和描边强化，不持续闪烁抢占画面 |
| 在线状态 | 低频轻微呼吸；离线不呼吸 |
| 业务面板、视频窗进入 | 轻量进入过渡，不使用夸张位移或旋转 |
| 云台、通话、共享、录制 | 按实际操作状态即时响应，模拟状态明确标注 |
| 减少动态效果 | 尊重系统设置，并提供界面内动态效果开关 |

不使用动态电紫、霓虹闪烁、无意义粒子或循环扫光。不得以假音量波形、假网络数据流等装饰冒充真实业务状态。

## 5. 界面结构与空间优先级

### 5.1 默认进入状态

1. 先展示卫星风格底图和个体热点。
2. 顶部仅保留紧凑的产品标识、快捷搜索和少量账号／全屏／消息操作。
3. 资源列表默认收起，由左上角入口展开。
4. 布局入口常驻地图底部；业务工具以紧凑悬浮入口出现。
5. 类型图例和地图标号保留可见，但控制体积。
6. 不默认打开视频、设备详情、推送或会议面板。

当前演示统计为 32 个设备点位、12 个有设备数据的省级地区，以及 4 个预置组合场景。演示数量不得表述为生产环境实时统计。

### 5.2 悬浮面板

资源、场景、设备信息、标绘、推送、会议、消息等均可悬浮在地图上，不以压缩地图宽度作为打开条件。

面板应支持标题区拖动、关闭和合理的最大高度；内容超出时在面板内滚动。资源列表可收起为紧凑入口，已选省份和本次筛选状态在面板收起后继续有效。

操作面板应靠近所属入口或关联画面，避免同时散开大量无关窗口。已打开的视频、地图热点和必要状态始终保持可识别。

### 5.3 主次关系

设备热点点击后的主体是视频画面，不先展示大块属性信息。信息从视频窗口内的“设备信息”入口查看。

云台、对讲和画面内容控制属于同一视频窗口的操作体系。辅助控制区在画面外展开，不叠压在监控内容上。

### 5.4 提示与确认

提示位于顶部中间的紧凑区域，正常情况下约 2.6–3.2 秒后消失。重点提示失败原因、产出结果、关键状态变化和耗时操作开始。

切换页签、图层、宫格、树节点等常规操作不连续弹成功提示。重复开窗、达到九窗上限、权限不足、设备离线等阻止性结果应明确说明。

关闭全部画面、清空全部标绘、替换当前场景、结束会议等破坏当前工作状态的操作需要二次确认。

## 6. 地图与高清显示

### 6.1 默认底图效果

默认呈现参考截图的卫星影像风格：山体纹理、城市肌理、农田、海岸、水域、金色道路及中文地名。范围应比早期仅展示京津局部的背景更广，体现周边区域态势。

本版使用本地素材完成产品交互原型，不调用真实卫星或道路服务，不要求地图密钥。原型内常驻“演示影像／非真实地理定位”说明。

### 6.2 高清素材与分层

- 九块高清素材组成 3×3 分块，每块原生尺寸为 1672×941。
- 总采样规模为 5016×2823，采用无损 WebP 编码。
- 全景底层负责区域连续性，分块边缘做显示过渡。
- 城市地名与道路路牌为独立矢量文字，不烘焙在低分辨率图片中。
- 热点、文字、界面控件与模拟视频按各自图层绘制，避免随一张背景图整体缩放变糊。

这些参数描述演示素材，不代表真实地图瓦片层级、实际覆盖公里数或地理精度。

### 6.3 4K 清晰度要求

| 验证场景 | 要求 |
| --- | --- |
| 3840×2160，100% 显示缩放 | 默认 1×视图的主体分块不超过原生像素尺寸展示 |
| 1920×1080 CSS 视口，200% 高 DPI | 输出物理像素仍按 4K 检查，不能只按 CSS 尺寸判断清晰度 |
| 地名、热点、图标、面板文字 | 独立渲染；字体与控件适配高分辨率视口 |
| 资源面板与图例 | 不互相遮挡，按钮与主要正文可辨认 |
| 高 DPI 态势快照 | 可导出 3840×2160 PNG |

清晰度承诺针对已验证的默认 1×视图。2×、4×等高倍放大仍受演示素材分辨率限制，不能宣称无限放大或等同于真实逐级卫星瓦片。

### 6.4 地图操作

支持滚轮缩放、按钮缩放、拖拽平移、热点／资源定位和视图复位。缩放保持鼠标附近的观察位置稳定。

当前卫星演示的交互倍率为 1×至 4×，达到边界时相应缩放按钮禁用。可拖拽范围受演示素材边界约束。

原型在切换到超出演示区域的省份时，可重新放置同一组背景来完成定位交互；这种背景重放应保持演示说明，不表示地理影像已真实切换。

### 6.5 图层

| 图层入口 | 含义 |
| --- | --- |
| 卫星演示 | 默认卫星风格演示视图 |
| 路网强调 | 对同一演示背景调整视觉强调，不表示加载了另一套真实道路服务 |
| 行政区参考 | 独立的行政区地理数据参考视图，不作为默认卫星底图 |

支持热点名称、底图信息与动态效果的独立显示控制。城市地名与路牌属于底图文字层，区别于设备热点名称。

三维视图不纳入本版交付，不以占位按钮暗示已具备真实三维能力。

### 6.6 右下角地图标号

固定三行，不允许用户在产品内随意编辑：

1. 审图号：`GS(2024)第 1268 号`，旁边明确标记“演示占位”。
2. 底图版本：`V1.2.3`。
3. 底图更新日期：`2026-11-04`。

这里的日期为最后原型的底图展示字段，区别于本文修订日期 2026-11-05。

点击标号查看来源和演示说明。普通浏览可临时隐藏，但态势快照必须强制带出这三行信息及演示属性。

以上审图号、版本和日期均是原型展示占位，不代表当前生成式素材的正式资质。未来接入正式底图时应使用服务商提供的真实标识。

## 7. 热点图标、状态与图例

### 7.1 九项图例

| 图例 | 图标语义 | 表达内容 |
| --- | --- | --- |
| 资源 | 信号塔／通用音视频符号 | 通用音视频资源入口 |
| 组合场景 | 叠层／多画面符号 | 保存的窗口组合与布局，不是设备副本 |
| 监控画面 | 摄像机符号 | 固定监控画面入口 |
| 可控制 | 调节／控制符号 | 具备远程控制能力的资源 |
| 云台设备 | 球机／云台符号 | 具备方向与光学控制能力 |
| 监控对讲 | 耳麦／对讲符号 | 具备双向通话能力 |
| 固定作业点 | 固定设施符号 | 常设作业地点 |
| 移动作业点 | 车辆／移动终端符号 | 车载、便携等移动资源 |
| 飞机 | 飞行器符号 | 无人机或通航资源 |

每项必须同时具备可辨认的符号和图例文字，不能只用一批相同圆点加不同颜色来区分。

### 7.2 三个独立维度

1. **设备性质／场景性质**：由主图标和类型名称表达。
2. **在线状态**：在线可有轻微呼吸，离线统一降灰且停止呼吸，符号形状保留。
3. **控制／对讲能力**：通过小型能力标记及窗口内操作入口表达，不能与设备类型和在线状态混为一类。

不同类型可以具备多个能力；普通“可控制”不能被当成生产系统中必然支持完整云台协议的证明。

### 7.3 个体展示与避让

所有缩放级别均保留个体图标。禁止将区域设备替换为数字圆形聚合簇。

重叠时可在屏幕空间做图标避让，并用引线指示原位置。正式产品的设备坐标不可被用户手工拖改；演示底图不承担精确坐标定位承诺。

悬停显示名称、类型、在线状态和主要能力。选中时强化边框和短暂定位环。名称可由显示开关或放大后的视图策略控制。

### 7.4 热点交互

- 单击设备热点：同步选中资源树，直接打开该路画面。
- 再次点击已开设备：聚焦已有窗口，不重复创建。
- 双击设备热点：兼容直接开窗，但不能绕过重复检测或九窗上限。
- 点击组合场景热点：快速打开关联画面组合。
- 右键设备热点：开窗、定位、推送、复制编号。
- 地图热点不支持人工拖动修改设备地理位置。

### 7.5 筛选

设备筛选的省份、状态、类型和文字查询按交集生效。图例项支持逐项开关，关闭后对应设备立即从当前视图隐藏，图例置灰。

组合场景是独立入口；其成员设备的状态分别处理，不把一个混合状态组合强行解释成“全部在线”或“全部离线”。关闭资源视图中的某设备不等于从保存的场景定义中删除该设备。

说明：这是为单列紧凑导航选定的一组常用简称，并不否认蜀、黔、滇、秦等其他常用称谓。界面中固定使用一套，悬停显示完整名称。

### 8.3 省份切换规则

1. 点击简称后高亮当前省份，并更新资源范围标题。
2. 列表筛选到该省，展开相应省／市／区县层级。
3. 地图平滑定位到所选地区的演示视野；行政区参考视图中可突出省界。
4. 保留文字、类型和状态筛选，按交集计算结果。
5. 如果此前所选资源不属于新范围，清除其当前选择路径，避免误操作旧资源。
6. 没有演示设备的省份仍可点击，不伪造资源；显示明确空状态及“返回全国资源”入口。
7. “全国”恢复全省份范围；“清除筛选”同时恢复全部省份、全部状态、全部类型并清空查询。

### 8.4 四级资源树

层级为省 → 市 → 区县 → 点位。省、市节点用于展开／收起；区县显示当前筛选范围内的点位数；点位显示类型符号、名称、编号和状态。

点击点位即定位并开窗，遵循重复检测和九窗上限。路径形如“四川省／成都市／天府新区／太平作业平台”。

当前会话中保留节点展开状态；刷新后恢复默认展开策略。

### 8.5 快捷状态筛选

提供全部、在线、离线、可控、云台五项。状态筛选与图例类型、省份和搜索同时生效。无结果时给出原因或清除筛选入口，不显示难以理解的空白树。

## 9. 组合场景

场景保存资源引用和排布，不复制设备本体。

每项显示场景名称、描述、窗口数量与布局档位。支持把当前窗口组合保存为新场景，名称必填；本地保存后刷新可再次使用。

从场景列表打开时：说明会替换当前窗口组合，确认后依次打开成员，恢复保存的宫格或自由布局。离线成员保留其离线占位，不伪造视频。

地图场景热点用于快速开组合画面；最终业务要求其排布含义与保存场景一致，不能误导用户为另一份资源。

当前原型存在两种入口差异：场景列表会恢复保存的布局；地图场景热点采用快速追加并进入自由布局。此差异列为待统一项，不宣称已经实现“所有场景入口完全同一排布”。

## 10. 搜索与搜索历史

### 10.1 文本搜索

顶层快捷搜索和资源内搜索保持查询内容同步。输入即过滤，匹配点位名称、编号、省、市、区县及类型名称，不区分大小写。

有查询时自动展开命中层级；地图保留匹配设备。查询与省份、类型、状态按交集计算。确认执行查询时可定位到匹配范围。

无结果时显示“未找到匹配资源”，并建议调整名称、地区或筛选条件。

### 10.2 语音搜索

搜索框内放置麦克风入口。流程为开始聆听 → 显示状态与识别原文 → 用户校正／确认 → 执行搜索。

支持演示自然表达，例如“成都的球台”“太平作业平台”，其中球台等常见说法映射到云台类查询。本版不宣称具备完整自然语言理解系统。

浏览器不支持、麦克风未授权、未检测到语音或识别服务网络失败时，应明确提示，可重试或直接输入原文。示例查询按钮用于试用搜索，不伪装为已经完成录音识别。

### 10.3 历史

最近十条有效查询保存在本机浏览器，支持复用、单条删除和全部清空。历史去重，新查询置顶，不上传服务器。

## 11. 视频开窗与窗口布局

### 11.1 开窗入口与限制

入口包括设备热点、资源点位、资源底部开窗按钮、设备信息动作、组合场景等。

同一设备最多存在一个当前窗口。重复打开时聚焦旧窗口并给出说明。窗口总上限九个，超出时明确阻止。

### 11.2 五种布局

| 模式 | 排布 |
| --- | --- |
| 自由 | 用户拖动和缩放窗口 |
| 2 宫格 | 左右等分 |
| 4 宫格 | 2 行 × 2 列 |
| 6 宫格 | 2 行 × 3 列 |
| 9 宫格 | 3 行 × 3 列 |

按窗口创建顺序填入宫格。超出当前格数的窗口只隐藏，不删除，切回自由布局恢复可见。

在宫格中拖动窗口即退出宫格，切回自由布局。画面位置不受底图缩放影响；选中窗口提升层级并高亮描边。

### 11.3 自由布局与清空

标题条拖动，右下角缩放；在低尺寸下仍保留必要的关闭、画面和操作入口。窗口不能被调整到完全不可操作。

“清空全部画面”二次确认后关闭全部窗口并回到自由布局；相关对讲、录像和输入状态随所属窗口正确结束。

跨分辨率保存布局应使用相对容器的归一化坐标。当前原型保存的自由场景位置包含像素值，不能直接保证跨不同分辨率准确复现，列为后续统一项。

## 12. 视频窗口与画面内容控制

### 12.1 窗口构成

标题条包含状态点、名称、类型及云台快捷入口、推送、窗口最大化、关闭。

主体区域是画面。画面上可显示名称、时间码、分辨率、演示编码／帧率说明和模拟水印；这些元数据为演示标识，不是实际链路测速或真实监控指标。

下方是画面内容工具条。云台与对讲操作归属于当前视频，与内容控制处于同一操作体系。

### 12.2 内容控制项

| 操作 | 业务含义与状态 |
| --- | --- |
| 播放／暂停 | 暂停或恢复当前模拟场景，不关闭窗口 |
| 静音／音量 | 控制该窗口的演示音量状态；当前没有真实音轨 |
| 录像 | 开始录制本地模拟画面，再次点击停止并生成 WebM 文件 |
| 原始比例／铺满 | 切换画面适配方式，不改变资源类型 |
| 电子放大／复位 | 独立于设备光学变倍的画面放大；当前原型为 1×／2×切换 |
| 水平翻转 | 翻转画面显示，不修改设备方向坐标 |
| 画面全屏 | 经浏览器允许进入／退出全屏 |
| 窗口最大化／还原 | 调整当前窗口占用的工作区尺寸，不等同于浏览器全屏 |
| 抓拍 | 生成带名称、时间及模拟说明的 PNG |
| 设备信息 | 按需查看属性，作为次级信息入口 |
| 云台／对讲 | 打开所属视频的辅助控制，受能力和在线状态限制 |
| 推送／邀入会商 | 将当前资源带入对应业务流程 |

关闭窗口时，正在进行的本地模拟录像应结束并处理导出，不能遗留无人管理的采集任务。

### 12.3 不遮挡原则

云台展开前后的原有画面宽高保持不变。辅助区在画面外展开，可增加窗口整体高度或调整其位置，但不能压在画面上，也不能靠缩小画面腾出空间。

对讲状态放在画面外的独立状态行，避免遮住监控内容。工具较多时保留可访问的滚动或溢出入口，不将操作面板覆盖画面。

### 12.4 离线画面

离线资源可开占位窗口，用清楚说明代替画面。不显示假直播，不显示假实时数据。云台、对讲、录像等依赖在线链路的动作应置灰并说明原因。

### 12.5 设备信息

设备信息包含类型、在线状态、四级归属路径、设备编号、分辨率、控制／云台／对讲能力。需要时显示控制持有人。

预览画面与已开窗口引用同一资源语义；离线时均显示离线说明。信息面板内可提供开窗、云台、对讲、推送、邀入会商和定位动作，但不改变“视频为主、信息为辅”的入口顺序。

## 13. 云台、光学与控制权

### 13.1 能力与入口

云台和远程控制操作由设备能力决定。当前原型用本地能力配置展示界面；生产接入应由设备台账或服务端能力下发，不能只凭类型名称推断协议能力。

### 13.2 云台方向

八个方向加中央归位。按下方向键产生对应指令，松开或取消输入时产生停止动作。模拟画面可表现响应，但不得用持续旋转动画冒充真实长按指令链路。

离线、未获得控制权或能力不支持时不可执行。

### 13.3 速度、变倍与光学

- 响应速度：1–100，默认 50，左慢右快；切换点位保留本会话上次速度。
- 设备变倍：1–12 倍，并显示当前倍率。
- 聚焦加／减、光圈加／减分别成对呈现。
- 变倍、聚焦、光圈分别记录，不互相覆盖；电子画面放大也不覆盖设备变倍值。
- 当前光学响应为模拟，不表示真实焦距、光圈或成像质量测量。

### 13.4 预置位

每路设备六个预置位，单击调用，长按两秒保存当前位置与对应光学状态。未设置时明确提示设置方式。

预置位归属设备，切换点位不共享；本版演示预置位仅保留在当前会话。

### 13.5 控制权

需求为同一路资源同一时间只允许一个有效控制方。

他人持有时显示持有人，提供请求控制；请求后显示排队，获得后显示本席位控制中。释放或窗口结束控制时清理输入焦点及相关状态。

当前原型使用本地模拟排队和移交，不能作为真实跨客户端控制权互斥或超时仲裁的验证。

## 14. 监控对讲

仅对具备对讲能力的资源提供视频工具条入口；非对讲资源不显示该工具条按钮。详情区若保留统一栅格，需明确说明不可用。

状态流为：空闲 → 发起 → 对端振铃 → 接听后双向通话 → 任一方挂断 → 空闲。发起后可取消，通话中可由本端或对端结束。

窗口工具条与状态行同步显示振铃／通话／结束状态。关闭窗口时结束所属通话状态。

当前通过“模拟接听”“模拟对端挂断”等动作验证流程，没有真实音频通道，不显示假实时声波。

## 15. 地图标绘

### 15.1 工具及样式

| 工具 | 交互 |
| --- | --- |
| 自由画笔 | 按住拖动形成连续轨迹 |
| 直线 | 起点按下，拖动到终点 |
| 矩形 | 拖动确定对角范围 |
| 椭圆 | 拖动确定外接范围 |
| 箭头 | 拖动确定方向，生成箭头端点 |
| 文字 | 先输入内容，再单击地图落点 |

提供四种线色与细／中／粗三档线宽。颜色应在卫星背景和深色参考图上都可辨认。

### 15.2 操作规则

标绘作用于地图任意可用区域，不局限在某个视频窗口内。进入绘制模式后切换地图手势；选择“返回地图浏览”或退出标绘后恢复平移。

标绘锚定地图内部坐标，随地图缩放和平移，不随视频窗口移动。演示坐标不解释为精确地理采集坐标。

文字落点固定，可撤销与删除，不支持拖动修改位置。按下但未形成有效距离的形状不应留下无意义图元。

### 15.3 管理与导出

支持撤销、重做、逐项显隐、逐项删除和清空全部。清空需确认。

支持 GeoJSON 导出和随态势 PNG 一起输出。导出内容保留图形类型、名称、颜色、线宽等必要信息；生成式演示背景下导出的坐标不应作为真实测绘或作业定位依据。

标绘本版保留在会话内，刷新不承诺恢复。

## 16. 推送

### 16.1 内容和权限

推送当前选中资源的画面，或当前地图态势。地图态势包含视野、热点和标绘的业务上下文。

权限两档：仅查看画面、查看并控制；默认查看并控制。控制仍应受设备能力与唯一控制权约束。

会议共享只传画面，不因推送权限选择而获取对方键鼠控制。

### 16.2 四类目标

| 目标 | 可用条件 | 回执表达 |
| --- | --- | --- |
| 屏幕 | 有可选屏幕 | 已下发或失败 |
| 联系人 | 有可选联系人，可展示离线 | 待响应、离线失败或其他失败 |
| 群组 | 有群组及成员 | 按成员逐个显示结果 |
| 进行中的会商 | 当前存在会商 | 已共享；会商已结束则明确失败 |

允许跨类别选择多个目标。无进行中会商时该类别不可选；提交时再次校验会商状态。未选目标不得提交。

### 16.3 记录与重推

记录包含编号、时间、内容、来源、权限和逐目标结果，支持查看与再次推送。本版记录存本机浏览器。

正式业务的重推应重新计算目标状态并执行投递。当前原型“再推一次”复用模拟记录产生新回执记录，不作为真实重发服务或投递可靠性验证。

## 17. 会议／会商

### 17.1 入口与创建

从地图工具、设备信息或视频窗口发起；设备入口应携带当前资源。无进行中会议时，可输入主题、选择演示成员并创建；已有会议时可邀入资源。

展示九位会议号，按三位分组显示，可复制。成员区域展示姓名、席位／角色及相关会中状态。

离线邀请给出失败说明，不伪造其已加入。原型中的成员加入为本地模拟。

### 17.2 三类共享来源

| 来源 | 当前表现 |
| --- | --- |
| 地图态势 | 本地模拟共享状态 |
| 电脑屏幕 | 浏览器授权后采集并本地预览 |
| 应用窗口 | 浏览器授权后选择并本地预览 |

只共享画面，不接管键鼠。切换共享前停止旧来源。共享中显示状态和停止入口；用户取消授权或浏览器不支持时说明原因。

结束会议、停止共享或浏览器结束采集时，应停止媒体轨道并清理共享状态。

### 17.3 会中消息与附件

会中消息面向全体与会成员，支持文字和附件，显示发送人、时间及内容。附件以文件行显示，可在本地打开／下载。

会中消息与普通群聊分开归属。正式业务按会议号隔离会话与历史；不能将普通群聊、前一场会议和当前会议的数据混在一起。

当前原型已分开普通聊天与会中消息，但会中消息使用会话级演示列表，多场会议按会议号隔离和历史归档尚未实现。

### 17.4 会议结束

结束会议需确认。确认后关闭会议状态、停止共享，并使相关推送会商目标失效；不删除普通群及其消息。

麦克风按钮在原型中是演示状态切换，不代表真实会议信令已接通。

## 18. 普通消息中心

独立于会商提供普通消息入口。当前演示包含群聊、联系人会话和系统通知三种会话示例，不代表完整即时通信后台。

切换会话显示对应的消息记录；支持输入文字、发送、回车发送和本地附件。中文输入法组合输入期间不能误触发送。

发送内容只加入本地演示会话，不通知真实联系人。消息面板关闭再打开可保留本次会话内容；刷新后的消息和附件恢复不纳入本版承诺。

会商结束不删除普通消息。群创建／解散、成员管理、跨设备消息同步、已读回执和服务端历史不纳入本版范围。

## 19. 附件、抓拍、录像与态势导出

| 输出 | 要求与边界 |
| --- | --- |
| 消息附件 | 单文件上限 20MB；显示名称与大小，超限明确提示；本地文件引用不表示已上传服务器 |
| 视频抓拍 | PNG，包含资源名称、时间和模拟画面说明；不宣称本版抓拍为真实监控原帧 |
| 模拟画面录像 | 浏览器支持时输出 WebM；再次点击停止并生成文件 |
| 地图标绘 | GeoJSON，保留图元及样式属性；演示坐标不作测绘依据 |
| 态势快照 | PNG，包含当前背景、热点、标绘及强制地图标号；独立文字保持清晰 |
| 高 DPI 快照 | 在对应显示设置下可导出 3840×2160 |

浏览器不支持录制、全屏、媒体采集或下载时应给出说明。普通屏幕截图与态势导出不同，不能把未实现的窗口内容、全站录屏或大屏投放混为同一能力。

## 20. 账号、统计与权限表达

原型显示演示姓名和席位，可进入账号与权限说明。它不是生产登录系统，不保存真实账号凭据。

在线／离线总量如展示，应代表全量演示数据，不随当前搜索和筛选改变；区域点位数随筛选改变。统计不应扩成占据大量地图面积的仪表盘。

当前 32 个设备示例为 28 个在线、4 个离线；具体数字只用于本地演示。能力不可用、设备离线、控制权不归本端等情况分别说明，不能统称网络错误。

正式权限应覆盖资源可见范围、控制、对讲、推送、会议、标绘和导出，由服务器鉴权；当前本地按钮限制不能代替服务端鉴权。

## 21. 本地状态与生命周期

| 数据 | 当前保存范围 | 刷新／关闭后的要求 |
| --- | --- | --- |
| 最近十条搜索 | 本机浏览器存储 | 刷新可恢复，可删除、清空 |
| 已保存组合场景 | 本机浏览器存储 | 刷新可恢复资源组合和已保存布局数据 |

本地保存失败或被浏览器限制时不应伪报成功。正式产品的持久化、并发一致性和用户隔离另行设计。

## 22. 核心业务流程

### 22.1 找资源、看画面

进入卫星演示 → 展开资源 → 点击省份简称或搜索 → 在地图／列表找到个体资源 → 单击开窗 → 画面内使用内容控制 → 按需查看信息、推送或邀入会商。

### 22.2 云台和对讲

打开在线且具备能力的资源 → 从视频工具条进入 → 在画面外展开控制区 → 获得控制权 → 方向／速度／光学／预置位操作；需要通话时发起 → 模拟振铃 → 模拟接听 → 双向通话状态 → 任一方挂断。

### 22.3 多路场景

打开多路画面 → 选择宫格／自由布局 → 保存组合场景 → 重新进入场景列表 → 确认替换 → 恢复组合。切换较小宫格时隐藏超出画面，切回自由布局恢复。

### 22.4 标绘和推送

选择标绘工具 → 在地图落点／拖动 → 调整颜色线宽 → 撤销／重做或管理图层 → 选择推送地图态势／某路画面 → 选择权限和目标 → 提交 → 检查逐目标回执 → 查看记录或再次推送。

### 22.5 会商与消息

从地图／资源发起 → 创建会议并邀请成员 → 复制会议号 → 选择共享来源 → 发送会中消息／附件 → 停止共享或结束会议。普通消息在独立消息中心处理，会议结束后仍保留普通会话。

## 23. 异常与降级

| 情况 | 界面处理 |
| --- | --- |
| 演示底图素材加载失败 | 明确显示文件加载失败，不表述为真实地图服务已连接 |
| 某省没有演示资源 | 空状态＋返回全国入口，不造设备 |
| 搜索无结果 | 明确提示，可修改查询或清除筛选 |
| 同设备重复开窗 | 聚焦旧窗，不新增 |
| 超过九窗 | 阻止新增并说明上限 |
| 设备离线 | 灰色状态、离线占位、依赖在线动作禁用 |
| 他人持有控制权 | 显示持有人及请求入口，不直接执行控制 |
| 无进行中会商 | 推送的会商目标不可选 |
| 提交前会商已结束 | 对该目标回执失败，不伪报共享 |
| 麦克风／屏幕权限被拒绝 | 说明拒绝或取消，保留可继续使用的文字搜索等入口 |
| 浏览器不支持录制／全屏／共享 | 明确提示，不伪造成功状态 |
| 附件超过 20MB | 阻止加入并说明上限 |
| 剪贴板权限不足 | 提供可手动复制的编号内容 |
