# 地图热点 · 离线交互原型

此处提供第一版视觉风格、4K 高清演示底图的离线原型包。

## 下载方法

**[点击这里下载原型压缩包（约 28.8MB）](https://github.com/sou131685-sys/PM/raw/refs/heads/main/downloads/map-prototype-4k.zip)**

如果直接下载没有开始：

1. 打开 [压缩包文件页面](https://github.com/sou131685-sys/PM/blob/main/downloads/map-prototype-4k.zip)。
2. 点击页面右上角的向下箭头 **Download raw file**（下载原始文件）。
3. 下载后解压，使用 Chrome 或 Edge 打开 **地图热点-首版视觉4K.html**。

无需安装依赖或联网。若仓库要求登录，请使用拥有该仓库访问权限的 GitHub 账号登录。

## 版本说明

- 恢复第一版深蓝半透明视觉，保留省份简称快捷栏、个体热点和画面优先交互。
- 卫星风格背景为生成式演示素材，采用 5016×2823 分块和独立地名文字；不代表真实卫星数据或权威地理定位。
- 已检查 4K 默认视图和 200% 高 DPI 显示；高倍率放大仍受素材分辨率限制。
- 视频、设备控制、对讲、推送和会议为产品交互演示。
